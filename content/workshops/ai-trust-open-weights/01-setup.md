All lab work happens in your web browser; there is nothing to install. Before you start Lab 1, confirm you can reach the environments below.

## What You Need

- A laptop with a current web browser

## What You Will Use

| **Environment** | **What it is** | **Used in** |
| --- | --- | --- |
| **PseudoCo Assistant** | The multi-agent healthcare assistant you prompt, running on Cisco Secure AI Factory with NVIDIA, using NVIDIA NIM microservices and Nemotron open models | Lab 1 and Lab 2 |
| **Splunk Agent Observability** | Evaluates and scores every agent interaction; reached through Cisco Cloud Control | Lab 1 |
| **Cisco Cloud Control** | Cisco's single sign-in point for its cloud applications, opened from the splash page; you reach Agent Observability and Agent Security here | Lab 1 and Lab 2 |
| **Agent Security** | Runtime guardrails on every prompt and response | Lab 2 |

## Access

![alt text](/images/image-210.png)

Go to https://dcloud2-sjc.cisco.com/content/instantdemo/cisco-secure-ai-factory-with-nvidia-hidden and click **View** to open the splash page, which has all of the tiles you will need for these labs. There will be more tiles than you will use.

{{% notice note %}}
Keep PseudoCo Assistant open in its own browser tab for the whole workshop. Both labs start in the assistant, and Lab 2 returns to it after you work in Agent Security.
{{% /notice %}}
