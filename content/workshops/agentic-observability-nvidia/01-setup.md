### 1. How to Access the Storefront

Go to the storefront URL provided by the facilitator and enter the access key when prompted. Each group has its own storefront instance (for example `acp1`, `acp2`); the instance name appears in the page title and is the same name you will look for in every console.

![alt text](/images/image-4.png)

### 2. How to Access Splunk Agent Observability

You should have received an email with instructions on how to access your assigned Splunk Agent Observability project. The project is **RetailAgenticCommerce** and your agent stream is named after your storefront instance.

### 3. How to Access Cisco AI Defense

You should have received an email with instructions on how to access Cisco AI Defense. The application you will work in is **ACP Retail Agents**.

### 4. How to Access Splunk Core

You should have received an email with instructions on how to access your assigned Splunk instance. The workshop index name is listed in that email.

{{% notice note %}}
Nothing in this workshop requires a terminal. Every lab is a console walkthrough against a storefront that the facilitator has already deployed and wired. Where a lab shows a configuration file or a command, it is there so you can see exactly what was added to the blueprint — and that nothing else was.
{{% /notice %}}
