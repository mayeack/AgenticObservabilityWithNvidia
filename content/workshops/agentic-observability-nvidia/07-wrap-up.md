## Outcome

**The gap.** NVIDIA AI Blueprints make the agent the easy part. The instruments — observability, runtime security, governance — usually arrive as code changes that fork the blueprint and have to be re-applied on every release.

**The value.** The blueprint ran exactly as NVIDIA ships it. Three additions were applied beside it as configuration and keys — a tracing block, a gateway URL, a collector — and one trace, captured once, answered the quality, safety, operations, and audit questions in the consoles built for each.

| **Outcome** | **What it means** | **Grounded in** |
| --- | --- | --- |
| **Unified Visibility & Control** | See every agent decision in every console that needs it, without forking the blueprint. | Architecture Overview |
| **Accelerated Time to Value** | Reference architecture to a running agentic application on your own GPUs, with NVIDIA's upgrade path intact. | NVIDIA AI Blueprint on AWS |
| **Improved Outcomes** | Agent quality, speed, and cost as operating metrics per agent and per model. | Splunk Agent Observability |
| **Trusted AI** | Written policy enforced at runtime on an application you did not write. | Cisco AI Defense |
| **Accountability & Evidence** | Every consequential decision attributable and explainable on demand. | Splunk Core |

**The ask.** Take the pattern, not just the demo: instrument beside the blueprint, never inside it. Every NVIDIA blueprint built on NeMo Agent Toolkit has the same `tracing` hook, the same model endpoint variable, and the same OpenTelemetry output — so the three additions you saw today apply to the next blueprint your teams deploy, unchanged.

Blueprint as shipped. Observed. Secured. Governed. **One trace, end to end.**
